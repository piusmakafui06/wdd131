Site Name

Logo

Wildlife

This name represents a webpage that is focused on providing documentaries and interesting facts about some animals in the wild.
Optional domain availability: www.wildlife.com

Site Purpose

The site provides information, documentaries, images, facts and details on some animals in the wild. The site is to help in researching on some animals and providing entertainment to wildlife enthusiasts.

Scenarios

  • Which animal is the fastest in the wild or on land?
  • Which animal can survive without food, and for how long?
  • In which country can kangaroos be found?

Color Schema

Colors to be used;

  • Green - On the headings
  • Green - On the backgrounds

Typography

The site will display only one font which is "Roboto".
This font will be used on the whole page.
